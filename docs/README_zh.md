# 计算时代（Computera）

Minecraft 26.1.2 / NeoForge 26.1.2.128 的计算机科技模组。

## 玩法

1. 合成**计算机机柜**，放入**计算卡**（I–V 级，线程数 2/4/8/16/32）；
2. 用**数据线缆**把机柜、终端和要控制的设备连起来（也可直接面贴）；
3. 右键**电传打字机终端**或 **CRT 终端**，在终端里用脚本控制计算机；
4. 程序保存在机柜硬盘上，可用打孔卡/闪存搬运。

## 终端命令（v0.1）

| 命令 | 作用 |
| --- | --- |
| `help` | 显示命令列表 |
| `ls` | 列出文件 |
| `cat <文件>` | 查看文件内容 |
| `edit <文件>` | 打开编辑器（Esc 保存并返回） |
| `run <文件>` | 运行程序 |
| `stop` | 停止当前程序 |
| `rm <文件>` | 删除文件 |
| `export <文件>` | 把文件写入主手硬盘/闪存 |
| `import <文件>` | 从主手硬盘/闪存读回文件 |
| `drive` | 列出主手硬盘/闪存里的文件 |
| `clear` | 清屏 |

打孔机：贴着终端放置。在终端里编辑或保存过某个文件后，拿着**空白打孔卡**右键打孔机，
会把该文件写入卡中；拿着**程序打孔卡**右键则把卡里的程序写回机柜。

## 交互一览

| 对象 | 交互 |
| --- | --- |
| 机柜 | 空手右键打开机柜界面（8 个计算卡槽 + 2 个硬盘槽）；手持计算卡/硬盘可直接右键插入；潜行+空手右键取出最后一张卡 |
| 电传打字机终端 | 手持纸带右键装纸（8192 行/卷）；没有纸带无法打开，输出每行消耗 1 行 |
| CRT 终端 | 右键打开**调度界面**（程序列表 + Run/Edit/Del/New/Stop/Refresh/Text）；需要电力，按 3 FE/t 从集群机柜扣除，断电会中断程序并提示 |
| 打孔机 | 手持空白卡右键写当前编辑文件；手持程序卡右键写回机柜 |
| 物流端口 | 手持物品右键设过滤；空手查看；潜行+空手清除 |
| EU 适配器 | 空手右键查看 FE 缓冲与 IC2 连接状态 |
| 计算卡 | 物品提示显示线程数 |
| 硬盘/闪存/打孔卡 | 物品提示显示文件数与前三个文件名 |

### CRT 调度界面

- 上半部分是程序列表，每行有 Run / Edit / Del；
- 右侧状态显示线程占用与当前运行的文件；
- **支持多人同时使用同一个终端**：各自打开同一个界面，共用一个线程和同一份输出；关闭界面只释放自己，不影响其他人；
- 下方是最近输出预览；
- 底部：New（输入文件名新建）、Stop、Refresh、Text（切回纯文本终端）；
- 电传终端仍是纯文本界面，纸带 8192 行/卷。

## 物流界面（CRT）

- 打开方式：CRT 界面点「物流」；
- **手持操作**：左键拿起整组 / 放下整组，右键拿半组 / 放一个；背包区（3 行 + 快捷栏）同样适用；关界面时手里的物品自动回背包；
- **翻页**：容器超过 27 格时用 `< 1/2 >` 或滚轮；
- **标签**：容器标签紧凑排列，超过 6 个用 `< >` 横向滚动；
- **改名**：在「名称」框输入后点「改名」，名称保存在机柜里；
- **分配模式**：点按钮开启 → 点多个容器标签（金色）→ 点源格，把一组物品平均分到这些容器；
- **原界面**：打开目标方块自己的 GUI，受限槽位（熔炉输出、专用燃料格等）用它操作。1.0.1 修复远程设备因自身距离检查而立即关界面的问题；必须保持在打开终端/显示屏位置 8 格内，目标设备必须仍加载、未被拆除且仍接入该集群。已进行箱子、熔炉、IC2 1.0.4 发电机的服务端菜单回归；使用专用打开协议的其他模组设备不保证兼容。

## 网络连接器（无线容器）

- 右键**机柜**：设为 hub；
- 再右键任意容器：绑定到该机柜，**不需要线缆**；
- 该容器会出现在物流页和 `devices` 里，名称形如 `chest_wireless_1`；
- 物流页、自动化规则和终端命令都可以按这个名字使用它。

## 物流（A + B）

### 物流端口（A）

- 贴在容器上，手持物品右键设置过滤，空手右键查看，潜行+空手清除；
- 端口加入所在集群，形成全网物品索引；
- 终端命令：

| 命令 | 作用 |
| --- | --- |
| `count <物品>` | 全网总量 |
| `find <物品>` | 分布位置（容器、槽位、数量） |
| `store <物品> [数量]` | 把背包物品送进过滤匹配的端口容器 |
| `take <物品> [数量]` | 从全网容器取到背包 |
| `ports` | 列出端口与过滤 |

- 脚本 API：`logistics.count(id)`、`logistics.find(id)`、`logistics.ports()`。

### 物流页 GUI 补充

- **发放模式**：底部「发放」进入；点任意容器格子取一个参照物品（也可以手持物品/已拿起的物品），
  点上方标签勾选多个目标容器，用 `- / +` 设每个容器发放的数量，点「发放」一次性送入所有目标；
- 物品来源按顺序：手里拿着的 > 背包 > 全网容器（自动从有货的容器扣）；
- 自动化页的「物品」栏新增**图标选择器**：点输入框右边的物品图标打开，
  分「网络 / 背包 / 主手」三页，点图标即可填入物品 ID，不用再手写标签。

### 网络显示屏

- 新方块：**网络显示屏**（4 块/次，玻璃 + 铜导线 + 铁锭）；
- 贴在完整方块的侧面，像展示框；多块**同朝向**且相邻的屏会自动拼成一块大屏，
  只有左上角那块负责渲染，显示整块屏的内容；
- 屏幕每 3 秒刷新所在集群的状态（中文短行）：物品数量/种类、容器/活跃、机柜/终端、线程、电力；
- **三种显示模式**：总览 / 物品（按数量排序的清单，物品名本地化）/ 容器（每个容器的存量）；
- **机器状态**：容器模式每行是「名字 数量 状态」，状态分 **运行 / 有货 / 空闲**；
  运行 = 方块状态里的 lit / active / working 等为真（熔炉、机器加工中），有货 = 没在跑但有物品；
  总览里的「容器 N 运行M」也是这个口径；
- 兼容其他模组机器：优先按“朝向面”取物品能力，取不到时退回无面能力，所以 IC2 的打粉机/电炉/压缩机等也会出现在容器清单里（名称跟随客户端语言）；
- 切换方式：CRT 界面右上角「屏显」→ 每一面墙后面点「总览 / 物品 / 容器」；
  每面墙各自记住模式，也能用 `/computera setdisplay <x> <y> <z> <overview|items|devices>` 设置；
- 屏幕必须贴着机柜、终端或数据线缆才能接入集群，否则显示“未接入集群”；
- **右键屏幕**：打开集群终端界面（和 CRT 终端一样，就近取一台终端）；
- **潜行 + 右键**：打开屏幕状态页（墙尺寸、完整数据、刷新）；
- 屏幕不受方块光照影响，夜里也能看清。

### 物流管道（B）

- 管道加入集群后，自动在“源容器 → 过滤匹配的目标端口容器”之间搬运物品；
- 瞬时传送，吞吐限制：**每条管道每 tick 4 个物品**；
- 没有管道时不会自动搬运，只能用命令/脚本。

## 集装箱

- 单个 **27 格**（等于原版箱子），配方：8 铁锭 + 1 箱子；
- **面贴**的集装箱合并成同一个容器：格位相加，最多 **64 个（1728 格）**；
  物流页、终端、管道、屏幕都把它当成**一个**容器；
- 超过 64 个时第 65 个会被拒绝放置；
- 拆掉其中一个：只掉它自己的 27 格物品，其余箱体重新分组；
  如果因此断成两堆，就变成两个独立容器，各自保留自己的物品；
- 右键打开翻页界面（每页 54 格，左上 `< 1/1 >`），Shift 点击在背包与容器间快速移动。

## EU 适配器

- 方块：EU 适配器，贴在 IC2 电缆/机器旁；
- 通过反射接入 IC2 的 EU 电网（不需要把 IC2 作为编译依赖），把收到的 EU 换算成 FE 存进内部缓冲（1 EU = 4 FE，单包上限 32 EU）；
- 自身暴露 FE 能量能力；可紧贴机柜供电，也可紧贴数据线缆，向该线缆连接的集群机柜供电；每个适配器总输出上限 1000 FE/t，断开线缆即停止该路径供电；
- IC2 未安装时方块仍可放置，只是显示“not installed”。

## 硬盘槽与硬盘程序

- 机柜有 **2 个硬盘槽**，可插入硬盘（每个硬盘 16 个程序文件）；
- 终端 `ls` 会把硬盘里的文件列成 `hd1:文件名` / `hd2:文件名`；
- `cat hd1:test.py`、`edit hd1:test.py`、`run hd1:test.py` 都支持；
- 从硬盘打开的文件保存时写回硬盘；拔出硬盘后文件仍在物品里。

## 计算卡

| 卡 | 线程 |
| --- | --- |
| I | 2 |
| II | 4 |
| III | 8 |
| IV | 16 |
| V | 32 |

单集群最多 32 台机柜、8 槽/机柜，理论上限 8192 线程。

## 兼容

- 使用 NeoForge 标准**物品**能力的容器/机械会被自动识别为 `devices.<方块名>_<序号>`；
- 使用标准**流体**能力的储罐/接口会被识别为 `devices.<方块名>_fluid_<序号>`；
- IC2: The New Era 的机器（26.1.2 分支）注册了标准物品/流体能力，因此其物品端口和流体端口可被脚本直接操作（风电部分不涉及）；
- EU 供电由可选 EU 适配器反射桥接 IC2 私有电网，并非标准 FE 接口；适配效果依赖 IC2 版本，需实机核验。


## 脚本与使用边界

- 这是自研 Python 风格子集，不支持 Python import 或第三方 Python 库。
- 容器提供 `size/get/id/count` 和同容器 `move(from,to,n)`；流体提供 `size/get/id/count`。
- 旧 `put/take` 接口会凭空生成或销毁资源，现已禁用并明确报错；请使用物流界面、管道或自动化规则搬运已有物品。
- 终端每台占 1 线程，运行程序额外占 1；当前没有设备通道扣费或程序排队。
- CRT 活跃时从主机柜扣除 3 FE/t，断电中断程序，不自动续跑。
- 通过终端或显示屏打开界面后，操作限同维度且距离打开位置 8 格内。
- 当前没有无人机系统。
