# Computera / 计算时代 — 当前实现规格

目标：Minecraft 26.1.2 / NeoForge 26.1.2.128，Java 25；modid 与主包均为 `computera`。

## 核心系统

- 机柜：8 个计算卡槽、2 个硬盘槽，保存内置文件、设备别名、分组、无线绑定和自动化规则。
- 计算卡：I–V 级，每张提供 2/4/8/16/32 线程。
- 集群：同维度，面贴或数据线缆/物流管道连接；搜索距离最多 64 格，最多 32 台机柜，线程容量封顶 8192。
- 线程占用：每个接入终端占 1，运行中的程序额外占 1；当前不实现设备通道计费、程序排队或每终端多程序并行。
- 电传终端：消耗纸带，每卷 8192 行；CRT：有查看者或运行程序时消耗主机柜 3 FE/t。断电中断程序，不自动续跑。
- 脚本：自研 Python 风格子集，经词法/语法分析编译成字节码；虚拟机按 tick 指令预算运行，支持函数、循环、列表、字典及 sleep。它不是 Python，也不支持 import、类或 try/except。
- 每集群每 tick 总脚本预算 200,000，活跃终端均分；耗尽当前批次预算会留到下一 tick，而非立即终止程序。

## 设备、物流与电力

- 容器脚本接口：size/get/id/count，以及同容器 move(from,to,n)。无资源来源的 put 和无目的地的 take 已禁用，会返回脚本运行错误。
- 流体脚本接口：size/get/id/count；put/take 同样禁用。当前没有安全的跨储罐脚本搬运接口。
- 脚本与界面共用设备发现逻辑，包括无线绑定和集装箱去重。
- 物流页支持存取、改名、分组、平均分配、按箱发放；自动化规则执行物品搬运。
- 物流管道：每条每 tick 4 个物品，通过事务搬运；无法完整完成的事务回滚。
- 集装箱：每个 27 格，相邻合并最多 64 个；界面每页 54 格，拆除只掉落本箱物品。
- 网络显示屏：相邻同朝向拼屏，支持总览/物品/容器模式，每 60 tick 刷新。
- 机柜暴露 FE 能力，不自带发电。当前没有机柜待机费或每活跃线程电费。
- EU 适配器通过反射尝试接入可选 IC2 私有电网，1 EU=4 FE，单包 32 EU；实际兼容性取决于 IC2 版本。
- 无人机未实现，不提供无人机命令或 API。

## 网络与会话

1.0.1：通过终端打开的原生菜单登记独立远程会话，服务端 tick、物品点击、配方及按钮操作使用终端锚点和设备连接校验代替目标的距离校验；普通就地打开的菜单保留原校验。使用服务端 Mixin 实现，不改变原生菜单类型、槽位或同步协议。已覆盖箱子、熔炉、IC2 发电机的打开入口和箱子物品操作；真实客户端显示与任意第三方自定义协议不在已验证范围内。

终端操作要求已建立会话、玩家存活且仍在同维度、距打开位置不超过 8 格。通过显示屏打开的终端以该显示屏为距离锚点。物流鼠标物品使用玩家原版库存菜单携带槽，不另存静态物品表。

## 代码结构

`registry` 注册；`block` 方块；`blockentity` 状态与行为；`cluster` 集群；`script` 编译器与虚拟机；`device` 设备适配；`logistics` 索引与搬运；`net` 网络；`menu` 容器；`client` 界面与渲染；`compat` 可选兼容。

## 验证入口

- `gradlew build`：编译、打包并执行 `scriptSelfTest`。
- `gradlew scriptSelfTest`：独立脚本回归检查。
- 服务端管理员命令 `/computera selftest`：在临时方块区检查集群、脚本、物流与电力，然后清理。
- `gradlew runAuditServer`：在 `build/audit-server` 启动隔离服务端，不使用开发存档。
- `/computera selftest` 包含双 FakePlayer 会话、关闭返还、取半组/放一个和越界拒绝检查；这不等同于双真实客户端网络验收。
- `/computera selftestpower`：需 IC2，在空中临时搭建燃煤发电机→铜线→EU 适配器→机柜，运行 200 tick 后报告结果并清理。
- `gradlew runAuditClient`：隔离客户端加载验收，不使用原开发存档。
- 已验证真实 IC2 1.0.4 发电机→铜线→EU 适配器→两段数据线缆→机柜，200 tick 测得机柜收到 7920 FE；拆断数据线缆后 20 tick 电量不再增长。每个适配器总输出上限 1000 FE/t，按机柜顺序充电。客户端成功加载资源与渲染初始化。
- 客户端仍需人工验收：双真实玩家联机、物流鼠标交互画面、集装箱翻页和显示屏渲染。
